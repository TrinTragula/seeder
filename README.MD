# Seeder

Find, show, share and admire Minecraft seeds, for Java & Bedrock Edition.

Works up to **26.3** on Java and **26.50 - 26.52** on Bedrock!

![Seeder demo gif](https://i.ibb.co/KxW0Fm4/seeder1-18-dim.gif)

Everything runs in your browser as a webapp:

- **[Seed map](https://mcseeder.com/seed/)**: open a seed on an interactive biome map. Find spawn, strongholds and structures. In the Overworld, the Nether and the End. At any height.
- **[Seed finder](https://mcseeder.com/finder/)**: describe the world you want, with biomes and structures near the world centre, and get a list of seeds that match. Open, save and share them.
- **[Seed lists](https://mcseeder.com/seeds/)**: hand-picked seeds for every kind of start
- **[Tools](https://mcseeder.com/tools/)**: Nether portal calculator, stronghold finder, slime chunks, circles, spheres and more to come

Works with every Java version from Beta 1.7 to 26.3, and with Bedrock from 1.18 to 26.52. A switch
on every page let you choose your edition. On Bedrock the biomes, the structures, the Nether, the strongholds and
the slime chunks follow Bedrock's own rules, checked against Mojang's Bedrock server. The spawn and the
End are approximate.

## Where's the code?

Seeder's code is closed source from version 1.5.0.

Versions up to 1.4.2 were published here under the MIT licence. I saw too many clones and decided this was the best thing to do.
